## Architecture Overview

To run production workloads on bare-metal Ubuntu 24.04 servers without a cloud provider's managed control plane, we design a **7-node High-Availability topology**:

- **2x Load Balancer Nodes**: Running HAProxy + Keepalived serving the floating Virtual IP (`192.168.10.100:6443`).
- **3x Control Plane Nodes**: Running `kube-apiserver`, `kube-controller-manager`, `kube-scheduler`, and a stacked **etcd Raft quorum**.
- **2+ Worker Nodes**: Running `containerd`, `kubelet`, and Calico CNI for application workloads.

## Bootstrapping the Stacked HA Control Plane

### 1. Initialize the First Control Plane Node (`master-01`)

```bash
sudo kubeadm init \
  --control-plane-endpoint "192.168.10.100:6443" \
  --upload-certs \
  --pod-network-cidr=192.168.0.0/16
```

### 2. Join Additional Control Plane Nodes (`master-02` & `master-03`)

Using the `--control-plane` and `--certificate-key` flags printed by `kubeadm init`, join the second and third control plane nodes to establish a 3-member etcd quorum:

```bash
sudo kubeadm join 192.168.10.100:6443 \
  --token <token> \
  --discovery-token-ca-cert-hash sha256:<hash> \
  --control-plane \
  --certificate-key <certificate-key>
```

### 3. Deploy Calico CNI & Verify etcd Health

```bash
kubectl apply -f https://raw.githubusercontent.com/projectcalico/calico/v3.28.0/manifests/calico.yaml
kubectl get nodes -o wide
kubectl -n kube-system get pods -l component=etcd
```
