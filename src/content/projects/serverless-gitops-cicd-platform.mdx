## Engineering Challenge

Traditional CI/CD pipelines often rely on imperative `kubectl apply` scripts from a central CI server and bottleneck on a single shared `staging` namespace. When multiple engineers push changes concurrently, staging becomes unstable, and production promotions lack an auditable declarative trail.

## Solution Architecture

We architected a two-repository GitOps delivery system demonstrated through the **Trailhead Supply Co.** (`app-services` and `app-services-gitops`) and **Finance API** (`finance-api` and `finance-api-ops`) reference platforms:

### 1. Ephemeral Pull Request Environments with Argo CD ApplicationSets

Instead of queuing on a shared staging environment, opening a Pull Request triggers the **Argo CD Pull Request Generator**:

```yaml
apiVersion: argoproj.io/v1alpha1
kind: ApplicationSet
metadata:
  name: preview-environments
  namespace: openshift-gitops
spec:
  generators:
    - pullRequest:
        github:
          owner: mkbntech
          repo: app-services
          labels: ['preview']
        requeueAfterSeconds: 60
  template:
    metadata:
      name: 'app-preview-pr-{{number}}'
    spec:
      project: default
      source:
        repoURL: 'https://github.com/mkbntech/app-services-gitops.git'
        targetRevision: HEAD
        path: overlays/preview
      destination:
        server: 'https://kubernetes.default.svc'
        namespace: 'preview-pr-{{number}}'
      syncPolicy:
        automated:
          prune: true
          selfHeal: true
        syncOptions:
          - CreateNamespace=true
```

### 2. Multi-Cluster Promotion (SNO Staging → HA Production)

Once the PR is validated and merged:

1. **Tekton (OpenShift Pipelines)** builds the immutable OCI container image, runs automated test suites, pushes the digest to the registry, and commits the updated SHA digest to `app-services-gitops`.
2. **Argo CD** automatically reconciles the **Single-Node OpenShift (SNO)** staging environment and the **HA Multi-Node OpenShift** production environment using environment-specific Kustomize overlays.
